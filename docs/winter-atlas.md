# Российская Арктика: зимний обзор 2025/26

Построены три месячные радиолокационные мозаики: декабрь 2025, январь и февраль
2026. Входные спутниковые данные — **Sentinel-1 GRD L1**. Готовые продукты L3
не использовались. Результат — обзор исходной радиолокационной амплитуды на
сетке **2 км**, а также карта доступности исходных сцен. Это первый региональный
слой проекта, **не карта обнаруженных льдин, стамух или границы льда**.

## Область и результаты

Морская аналитическая область простирается от 28° в.д. до 169° з.д., севернее
63,5° с.ш. до 89,99° с.ш. Она охватывает российские арктические моря и прилегающий
Арктический бассейн; площадь после вычитания суши — 6 253 085 км².
Эта рамка включает также прилегающие международные и иностранные акватории;
она не является границей России, её ИЭЗ или юридически определённой Арктической зоны.
Береговая линия Natural Earth 1:50 млн пригодна для обзора, но не для поиска
30-метровых целей возле берега. Белое море входит в рамку; отдельная подпись не нанесена.

| Месяц | Уникальных сцен в каталоге | Область внутри контуров сцен | Заполнение мозаики | Использовано в мозаике |
|---|---:|---:|---:|---:|
| Декабрь 2025 | 1 994 | 97,32% | 96,58% | 100 сцен |
| Январь 2026 | 1 779 | 97,31% | 96,44% | 100 сцен |
| Февраль 2026 | 1 537 | 95,36% | 94,26% | 100 сцен |

Каталог содержит **5 310 уникальных наблюдений**, карта доступности — 770 ячеек
со стороной 100 км. Разные упаковки одной съёмки не считаются разными наблюдениями.
Все 300 выбранных обзорных изображений прочитаны без ошибок. Оставшиеся сцены
учтены в карте доступности, но их растры не обрабатывались.

В мозаики вошли даты 6–31 декабря, 3–31 января и 3–28 февраля. Мозаика объединяет
разные дни, **не показывает состояние на один момент**. При перекрытии выбирается
более поздняя из отобранных сцен, а не обязательно последняя сцена всего каталога.
Изменение яркости между месяцами нельзя трактовать как измеренный дрейф или откол.

## Как получены изображения

1. CDSE STAC: поиск `sentinel-1-grd`, проверка уровня L1, пагинация, исключительная
   верхняя граница времени и отдельные запросы по обе стороны 180-го меридиана.
2. Вычитание суши, полярная равновеликая проекция EPSG:3576. Для каждого месяца
   выбираются до 100 сцен, добавляющих наибольшее покрытие на планировочной сетке 25 км.
3. Earth Search / публичные файлы Sentinel-1 AWS: чтение встроенных уменьшенных
   изображений амплитуды HH или VV. Фактически проверен анонимный HTTP-доступ;
   платный режим Requester Pays, ключи AWS и токены не использовались.
   Доступность этого зеркала в будущих запусках не гарантируется.
4. Логарифм DN и индивидуальная растяжка 2–98-го процентилей каждой сцены.
   Радиометрическая калибровка и удаление теплового шума в обзорной ветке не выполнялись.
   Яркость — отображение, **не Sigma0/Gamma0**, не вероятность льда и не его толщина.
5. Геопривязка по опубликованным GCP с TPS-перепроецированием, обрезка по контуру
   сцены и морской маске. Геометрическая точность независимо не измерялась.
   Размер ячейки результата 2 км не означает подтверждённую точность 2 км.

На стыках ожидаемы различия яркости и швы: смешаны даты, поляризации, орбиты и углы
падения. Эти швы не являются границами льдин. Для количественного анализа нужны
калиброванные сопоставимые съёмки в исходном разрешении.

## Файлы и открытие в QGIS

- `radar-YYYY-MM.png` — готовая карта месяца.
- `radar-YYYY-MM-amplitude.tif` — обзор в EPSG:3576; 1–254 — яркость, 0 — NoData.
  Открыть как одноканальный серый растр, диапазон 1–254.
- `radar-YYYY-MM-date.tif` — дата для каждого пикселя. Для ненулевого значения:
  `значение + 20250000 = YYYYMMDD`; например, 10131 означает 2026-01-31.
- `radar-YYYY-MM-scene-index.tif` — индекс сцены. Найти соответствующий
  `scene_index` в `radar-YYYY-MM-status.json`: там ID, время UTC, поляризация и URL источника.
- `coverage-grid.geojson` — сцены, дни с хотя бы одним пересечением и покрытая доля
  каждой ячейки по месяцам и режимам IW/EW. Число дней не означает, что вся ячейка
  наблюдалась в каждый из этих дней. `ice_objects=null`: объекты не классифицированы.
- `scene-footprints.geojson` — контуры каталога, а не контуры льда. Поле `processed=false`
  означает отсутствие обработки детектором объектов; обзорные чтения учтены отдельно в status.
- `domain.geojson` — аналитическая рамка без суши.
- `summary.csv/json`, `mosaic-summary.json` — раздельная статистика каталога и мозаик.
  Объём исходных файлов иногда отсутствует: `known_size_gb_lower_bound` — нижняя
  оценка по известным размерам, не оценка полного объёма загрузки.
- `validation.json` — проверка согласованности NoData, дат, источников, морской маски
  и геометрии у 180-го меридиана. Это не оценка точности распознавания.

NoData не означает отсутствие льда. Контуры GeoJSON разрезаны по 180-му меридиану
для корректного отображения в ГИС.

## Что происходит с требованием 30 м

Режим IW покрывает только 30–33% этой области за отдельный месяц; основную площадь
покрывает EW. У EW GRDM разрешение около 93 × 87 м, у IW GRDH — около 20 × 22 м.
Даже наличие IW не гарантирует обнаружение и классификацию цели диаметром 30 м.
Обзорные растры 2 км не пригодны для такого поиска и не должны подаваться в
`ingest-sar`, который требует линейную калиброванную Sigma0.

Полная карта отдельных льдин и стамух пока не построена. Следующий этап — обработка
серий IW в исходном разрешении, точная береговая маска, проверка по разметке и
наблюдение неподвижности во времени. Неподвижность сама по себе не доказывает
посадку на грунт; для стамух нужны дополнительные данные и проверка специалистом.
Этот архивный обзор не является действующей системой навигационного оповещения.

## Воспроизведение

Из корня репозитория после установки `python -m pip install -e ".[test,plot]"`:

```bash
python -m ice_monitor.regional --config config/russian_arctic_winter.json --output runs/russian-arctic-winter
python -m ice_monitor.radar_overview --input runs/russian-arctic-winter --month 2025-12 --max-scenes 100
python -m ice_monitor.radar_overview --input runs/russian-arctic-winter --month 2026-01 --max-scenes 100
python -m ice_monitor.radar_overview --input runs/russian-arctic-winter --month 2026-02 --max-scenes 100
python scripts/render_winter_maps.py --input runs/russian-arctic-winter --output runs/winter-maps
python -m pytest -q
```

Каталог и уменьшенные растры кэшируются. Для другой конфигурации используйте новую
папку: кэш GCP рассчитан для выбранной проекции. Региональная ветка запускается
вручную; постоянный мониторинг всей Арктики по расписанию ещё не включён.
