# Карта кандидатов в отдельные льдины — зима 2025/26

Дата расчёта: 18 сентября 2026. Входы: открытые Sentinel-1 **L1 IW GRDH** и
Sentinel-2 **Collection 1 L2A**. Использованы реальные пиксели исходных измерений.

**Результат частичный: пять участков 10 × 10 км, суммарно 500 км².** Это около
0,008% морской области прежнего арктического обзора, а не полная объектная карта
Арктики. 500 км² — геометрическая площадь участков; пригодная площадь каждой
сцены меньше из-за облаков, NoData и слабого радиолокационного сигнала. Участки
выбраны для проверки метода по повторным IW, а не для репрезентативной оценки
численности льдин или прибрежных стамух.

| Карское море | 41 | 4 | 126 |

Обработаны 20 радиолокационных наблюдений декабря 2025 — февраля 2026 и 15
оптических наблюдений февраля 2026. Счётчики относятся к наблюдениям, а не к
уникальным льдинам, отслеженным между датами. Нулевой результат не означает
отсутствие льда: сплошной покров может не распадаться на отдельные объекты.

Из 68 устойчивых контуров **29 не имеют границ, искусственно проведённых
алгоритмом разделения**. Их эквивалентные диаметры — 31,92–205,29 м; все находятся
на баренцевоморском участке. Они показаны по умолчанию. Это кандидаты, без
независимого подтверждения ледовой природы каждого малого пятна. Восемь пикселей
на сетке 10 м дают диаметр 31,92 м, но не доказывают разрешение/полноту на 30 м.

**Подтверждённых стамух: 0.** Ни одна радиолокационная цель не прошла критерий
трёх повторных наблюдений за 24 дня. Даже прохождение такого критерия означало
бы лишь повторяемость сигнала возле фиксированного места, а не доказанную
посадку льда на грунт. Независимые открытые наблюдения заземления этих объектов
за рассматриваемые даты не найдены и не использованы. Пустой слой означает
отсутствие доказательств в этой обработке, а не отсутствие стамух в морях.

## Файлы

- `map.html` — большая автономная карта всей аналитической области Арктики.
  Три месячные обзорные мозаики, пять участков, 15 оптических и 20 радиолокационных
  снимков размещены в общей проекции EPSG:3576. Выбор участка приближает карту;
  внутри доступны сенсор, дата, контур, координаты и исходная сцена. Выбор объекта
  приближает к нему. Масштаб на экране приблизительный, в единицах проекции.
  Дата участка не зависит от месяца обзорной мозаики: разные участки могут
  показывать разные даты. На обзорных метках даты подписаны явно.
- `detail-map.html` — прежний просмотр оптических фрагментов, сохранён отдельно.
- `isolated-stable-candidates.geojson` — 29 устойчивых кандидатов без искусственных разделений.
- `floe-candidates.geojson` — 215 полных контуров, включая спорные разделения.
- `threshold-stable-candidates.geojson` — 68 контуров, устойчивых к порогам.
- `excluded-truncated.geojson` — контуры, обрезанные краем или маской пригодности.
- `radar-targets.geojson` — 280 неклассифицированных радиолокационных целей;
  это не 280 льдин. `persistent-radar-targets.geojson` и
  `confirmed-stamukhi.geojson` пусты.
- `processed-areas.geojson`, `sar-coverage.geojson` — явная область обработки.
- `evidence/` — для каждой оптической даты снимок, карта, маска меток и источник.
  `labels.tif`: −1 — непригодно, 0 — нет выделенного экземпляра, >0 — номер
  экземпляра. Ноль не означает открытую воду. Обрезанные экземпляры присутствуют
  в маске и в отдельном векторном слое.
- `sources/sar/`, `optical-processing.json`, `radar-processing.json` — исходные
  URL, параметры, орбиты, даты и пригодная площадь каждой сцены.

GeoJSON: долгота/широта WGS84. Растры: EPSG:3576, шаг 10 м. Даты UTC.
Полноразмерные калиброванные фрагменты сохранены отдельным архивом растров;
большие бинарные файлы не включены в Git.

## Метод и границы применимости

Оптика: индивидуальные scale/offset Collection 1 применяются один раз.
Отрицательная отражательная способность исключается. SCL сохраняет снег/лёд
(класс 11), исключает облака/тени/NoData; облачный буфер 60 м. Сцены выбираются
по пригодности фактического участка, а не облачности целого гранула; три разные
даты. Отбор дат выполнен внутри 15–28 февраля, не всего зимнего сезона.

NDSI ≥0,4 и зелёный канал ≥0,18 задают маску. Независимая экспериментальная
реализация watershed по расстоянию разделяет соприкасающиеся части. Повторение
при порогах зелёного 0,15 и 0,21 даёт минимальный IoU; ≥0,6 считается устойчивым.
Это не вероятность и не научно установленная точность. Разделитель может
проводить прямые линии внутри одной льдины, а маска — объединять несколько.
Поле `inferred_boundary_fraction` показывает долю такой границы. Консервативный
слой требует строго нулевой доли, устойчивости и отсутствия обрезки.

Зелёный канал и RGB имеют шаг 10 м; SWIR и SCL исходно 20 м. Низкое солнце,
остаточные облака и снег на тонком льду затрудняют классификацию. Мелкие кандидаты
занимают несколько пикселей и остаются низкой уверенности.

SAR: чтение нативного окна IW, интерполяция LUT калибровки и шума по исходным
номерам строки/столбца, Sigma0=(DN²−шум)/LUT². Повторное вычитание уже удалённого
шума запрещено. Используются обе поляризации и пороги сигнал/шум. EW и обзорные
мозаики 2 км в этот детектор не допускаются. Геопривязка GCP/TPS — экспериментальная
морская аппроксимация без уточнённой орбиты; абсолютная точность не установлена,
результат калибровки не сравнивался независимо с SNAP. Радиолокационный контраст
может соответствовать торосам, судам или другим отражателям.

Береговая маска Natural Earth 1:50 млн с отступом 1 км грубая, а не 30-метровая.
Выбраны удалённые от этой маски морские участки; малые острова могут отсутствовать.
Для расширения на прибрежные стамухи требуется более точная береговая основа.

Не выполнены: полноценное покрытие Арктики, проверка точности по независимой
разметке, распознавание откола, единый трекинг SAR/оптика, доказанное заземление.
Обзорная съёмка EW не позволяет автоматически заполнить эти пробелы на масштабе
30 м; зимой высокоширотная оптика ограничена полярной ночью. Поэтому полный
запрошенный результат по всей Арктике пока не достигнут.

## Воспроизведение

Из корня репозитория, после построения регионального каталога (`docs/winter-atlas.md`):

```bash
python -m pip install -e ".[test,plot,objects]"
python -m ice_monitor.object_pipeline --plan config/object_validation_regions.json --overview runs/russian-arctic-winter --output runs/objects --sensor all --rgb
python -m ice_monitor.object_map --plan config/object_validation_regions.json --native runs/objects/native --overview runs/russian-arctic-winter --output runs/objects/detected
python -m ice_monitor.floe_instances --optical runs/objects/optical-c1 --selection runs/objects/selected-optical --overview runs/russian-arctic-winter --output runs/objects/floes
```

Для экспорта скопировать конфигурацию в `runs/objects/plan.json`, затем:

```bash
python scripts/export_object_results.py --input runs/objects --overview runs/russian-arctic-winter --output runs/object-map
python -m pytest -q
```

Общую карту можно пересобрать из готовых результатов без новой обработки снимков:

```bash
python scripts/build_arctic_map.py --results runs/object-map --overview runs/russian-arctic-winter --native runs/objects/native --output runs/object-map/map.html
```

Все изображения встроены в файл, внешние картографические сервисы не нужны.
WebP/JPEG используются только для отображения; аналитические растры и векторные
контуры не меняются. Для общей карты проверены состав данных и переключения
всех 35 сцен в эмуляции DOM. Визуальная проверка этой версии в браузере не
выполнена: открытие локального файла было заблокировано политикой браузера.

34 теста прошли локально. Проверены калибровочные формулы/LUT, отсутствие двойного
вычитания шума, границы/размеры полигонов, отбраковка отрицательной отражательной
способности, неоднозначность сопоставления и отсутствие необоснованных утверждений
о заземлении. Это инженерные проверки, не оценка полноты распознавания.
